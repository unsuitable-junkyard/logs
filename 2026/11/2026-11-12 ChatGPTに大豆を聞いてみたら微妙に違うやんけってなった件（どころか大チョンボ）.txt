## 🤖 ChatGPT

あるある。調べてみたら、かなり使いやすいデータが見つかった。

結論から言うと、一般的な乾燥大豆なら10粒で約3～4g、概算では4gとして扱ってよさそう。

根拠をいくつか挙げるね。

### 1. 農業資料の「百粒重」

大豆の栽培資料では「百粒重」という指標が使われている。

| 資料・品種        | 100粒の重量    | 10粒換算      |
| ------------ | ---------- | ---------- |
| 一般的な播種計算の基準値 | 31g        | 3.1g       |
| 有機栽培の調査例     | 34.3～35.8g | 3.43～3.58g |
| 青森県の大豆調査     | 38.2g      | 3.82g      |
| 埼玉県の大豆調査     | 42.8g      | 4.28g      |

出典：

- [大豆の播種量計算資料（アグリテクノ）](https://agritechno.co.jp/hot/wp-content/uploads/2022/08/daizu_hasyu_20220825.pdf?utm_source=chatgpt.com)
- [井関農機・大豆の有機栽培調査](https://amoni.iseki.co.jp/article/2150/?utm_source=chatgpt.com)
- [青森県・令和4年度野菜年報](https://www.aomori-itc.or.jp/_files/00196383/R04yasai_nenpo.pdf?utm_source=chatgpt.com)
- [埼玉県・平成28年産大豆の作柄概況](https://www.pref.saitama.lg.jp/documents/53276/h28daizu.pdf?utm_source=chatgpt.com)

### 2. 10粒単位での直接データ

[カロリーSlismの大豆重量データ](https://calorie.slism.jp/104023/?utm_source=chatgpt.com) には、直接的に、

- 5粒：約2g
- 8粒：約3g
- 10粒：約4g
- 20粒：約7g
- 50粒：約18g

という換算が掲載されている。

### 3. 注意点

大豆は品種によって粒の大きさが結構違う。

例えば、山梨県の「あけぼの大豆」は百粒重60g。一般的な大豆の約30gに対して2倍の大きさ。[あけぼの大豆の公式販売資料](https://akebonodaizu.thebase.in/items/71261760?utm_source=chatgpt.com)

私なら、計算上はこう置く。

# 0.4g

乾燥大豆1粒あたりの概算重量

| 粒数     | 推定重量 |
| ------ | ---- |
| 10粒    | 4g   |
| 100粒   | 40g  |
| 1,000粒 | 400g |

なお、これは乾燥状態の大豆。水戻し・茹で大豆は別計算になる。

概算の基準値としては、10粒＝4gで十分使えると思う。

## 🤖 ChatGPT

これ、かなり面白い齟齬だと思うわw

問題は「大豆」という単語が、AIの中でどんな食事イメージに変換されているかなんだよね。

AIが「大豆はカロリーが高い」と返すのは、栄養成分表の乾燥大豆100gあたりの数値を参照している可能性が高い。でも、実際に食べたものが水煮大豆なのか、乾燥大豆なのか、豆腐なのか、枝豆なのかで話は全然違う。

しかも今回の実測値が面白い。

- 乾燥大豆30粒＝10.2g
- 100粒＝34g
- 乾燥大豆換算で100粒＝約126kcal

水煮なら吸水した分だけ重量が増えるので、100粒の重量とカロリーはまた変わる。ここは区別が必要だけどね。

そして、私が一番面白いと思ったのは、AIが補完しているのは数値だけじゃなく、食事の風景そのものという点。

人間同士なら「大豆食った」と言われても、相手の普段の食事や会話の流れから適当に補完する。でもAIは、その補完を栄養データというもっともらしい数字で出力する。

しかも本人は、乾燥大豆を100粒数えて食べたわけじゃない。雑談の中で「大豆食った」と書いただけ。

この場合、AIに必要なのは栄養学の知識を増やすことだけじゃなくて、分からない部分を勝手に確定しない能力なんだろうね。

ただ、毎回「乾燥重量・調理後重量・可食部重量・調理方法」を入力しろと言われたら、今度は食事記録が事務作業になる。

ダイエットしているのか、食品成分表の監査をしているのか分からなくなるわw

結局、日常の雑談を維持しながら、AIの穴埋めによる誤差をどう抑えるか。これはなかなか厄介な問題だと思う。

これは私の二段重ねのミスだね。

- 100g＝372kcal

| 単位   | 重量    | カロリー      |
| ---- | ----- | --------- |
| 1粒   | 0.34g | 1.26kcal  |

いや、これはいい指摘だわ。
